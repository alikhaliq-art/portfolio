
# 🌐 Responsive Portfolio Website

## 🚀 Overview
This project is a **personal portfolio website** built using **HTML, CSS, and JavaScript**.  
It is fully **responsive** and optimized for desktop, tablet, and mobile devices.  
The portfolio highlights skills, projects, and contact details in a clean and modern design.

## 🎨 Features
- ✅ **Responsive Design** – adapts to all screen sizes (desktop, tablet, mobile).  
- ✅ **Navigation Bar** with smooth scrolling.  
- ✅ **Hero Section** with personal introduction.  
- ✅ **About Section** – details about skills and experience.  
- ✅ **Projects Section** – showcase of work with live/demo links.  
- ✅ **Contact Section** – includes form and social media links.  
- ✅ **Interactive Elements** using JavaScript (toggle menu, form validation, animations).  
- ✅ **Modern UI/UX** with clean CSS styling.

---

## ⚙️ Technologies Used
- **HTML5** – Semantic structure  
- **CSS3** – Flexbox, Grid, Media Queries for responsiveness  
- **JavaScript (ES6)** – Interactivity and DOM manipulation
